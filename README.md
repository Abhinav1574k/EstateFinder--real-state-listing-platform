# EstateFinder — Task 17

Real Estate Listing Platform built with HTML5, CSS3 and JavaScript.

## Implemented

- Property listing grid
- Search by keyword/location
- Minimum and maximum price filters
- Bedroom filter
- Property type filter
- Leaflet + OpenStreetMap map view
- Markers for filtered listings
- Property detail page with `property.html?id=<id>`
- Image gallery
- Responsive layout
- Listing data separated into `data.js`

## Run locally
open live server 
Open `http://localhost:5500`.

## Deployment

This is a static site. It can be deployed directly to GitHub Pages, Netlify, Vercel, or another static hosting service.

## Outcome

Task 17 requirements were implemented: listing grid, multi-criteria filters, interactive map, property detail page and image gallery.
